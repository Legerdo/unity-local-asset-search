## 우선 검증할 과제

- [ ] 실제 서로 다른 1천·5천·1만개 에셋을 임베딩한 검색 지연·메모리 측정. 파일·벡터 복제로 규모를 부풀리지 않습니다.
- [ ] 독립 청취 라벨을 갖춘 효과음 평가셋과 Recall/nDCG 평가. 현재 자동 참조 결과로 정확도를 확정하지 않습니다.
- [ ] 실제 GPU OOM과 복구, 낮은 VRAM 장비, 긴 오디오·문서 입력 확인.
- [ ] 장시간 반복 사용과 큰 인덱스의 메모리·취소·종료 검사.
- [ ] Unity 2021.3·6.5·6.6·7, macOS/Linux, 밝은 테마 실제 실행 확인. 새 Unity 설치를 필수로 요구하지 않습니다.
